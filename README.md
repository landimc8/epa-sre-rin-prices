# Do EPA Small-Refinery Exemption Decisions Move RIN Prices?
 
Python analysis of whether EPA small-refinery exemption (SRE) decisions move D4 and D6 RIN prices, using regression, classification and clustering.
 
Individual capstone project, **Advanced Data Analytics**, MSc in Finance, HEC Lausanne, Fall 2026. **Status:** in progress.
 
## Approach
 
- **Events:** 7 EPA SRE decision batches since 2022, split into a stricter 2022–2023 era and a more lenient 2025–2026 era.
- **Data:** 245 weekly observations compiled from EPA, EIA and USDA sources.
- **Methods:** regression (price impact), classification (direction of moves) and clustering (market regimes).
